# 🌦️ MyCityWeather

A modern, responsive Weather Dashboard built with **React.js**, **WeatherAPI**, and **BigDataCloud Reverse Geocoding API**.

The application provides real-time weather information, hourly and daily forecasts, air quality, weather highlights, interactive maps, charts, dynamic backgrounds, animated weather effects, and dark/light themes.

# ⚙ Installation

Clone Repository

```bash
git clone https://github.com/yourusername/weather-app.git
```

Move into Project

```bash
cd weather-app
```

Install Dependencies

```bash
npm install
```

Run Development Server

```bash
npm run dev
```

---

# 📦 Required Packages

```bash
npm install axios

npm install react-router-dom

npm install react-icons

npm install react-leaflet leaflet
```
